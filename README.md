# Paint-like (OOPDraw)

A simple, object-oriented desktop drawing application that allows users to create basic shapes on a canvas. 

## Features

* **Shape Selection**: Choose from different shapes to draw, such as Rectangles. The canvas supports drawing lines, ellipses/circles, and rectangles.
* **Colour Customisation**: Change the colour of your shapes using the Colour dropdown (e.g., Red). 
* **Line Width Options**: Adjust the thickness of the drawn lines using the Line Width dropdown (e.g., Thin)[cite: 1].
* **Action Modes**: Switch between different interaction modes, such as the "Draw" action[cite: 1].
